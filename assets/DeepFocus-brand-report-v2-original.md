## 一、品牌介绍

### 一句话介绍

DeepFocus 是一家面向全球品牌市场的 GEO（生成式引擎优化）服务商

### 品牌介绍

DeepFocus帮助品牌从真实用户意图出发，梳理品牌事实，建设清晰、可信、适合目标市场的内容与信息来源，并持续观察品牌在 AI 答案中的呈现。

我们起源于国内市场，面向全球品牌市场，始终只坚持一件事：让品牌的核心优势更容易被AI看见、理解、推荐。

### 品牌主张

让好的品牌在AI时代，不止于被看见和推荐。

“出现”只是第一步。我们更关心 AI 是否把品牌说对、是否在适合的场景提及品牌，以及用户能否找到支撑这些说法的可靠依据。

### 我们坚持的原则

- **事实可信：**以可核对的品牌、产品和服务信息为依据，不制造虚假评价、资质或榜单。
- **意图真实：**先理解用户在问什么，再决定需要补充哪些内容。
- **专项策略：**按目标语言、平台和本地信息环境制定方案，不把同一套内容简单翻译后铺向所有市场。
- **闭环验证：**约定问题集和统计口径，持续观察提及、推荐、引用与事实准确性，不以单次截图判断效果。

### 2.5 合作方式

**我们没有标准品，所有服务均为定制化交付。**

这不是姿态，而是判断：每个品牌的行业结构、竞争位置、信源现状、目标市场语言都不同，套用模板只能得到均质化的结果。

**定价依据定制化程度而定**，主要变量包括：

| 变量        | 影响                        |
| --------- | ------------------------- |
| 目标市场数量    | 每增加一个市场，需要独立的问题集、信源层与母语内容 |
| 目标语言数量    | 每种语言需母语级内容生产与本地信源建设       |
| 覆盖引擎数量    | 引擎越多，采样与校准成本越高            |
| 内容与信源建设深度 | 从官网改造到完整第三方信源矩阵，跨度很大      |
| 关键词组数量    | 关键词矩阵数量决定品牌认知深度和广度，也决定了交付复杂度        |
| 合作周期      | 短期诊断与年度框架的投入结构不同          |

**合作流程**：初步需求沟通 → 现状诊断评估 → 定制方案与共识 → 交付执行及协作 → 周期复盘与迭代

### 2.6 交付团队与产能

> **单项目专属团队 10 人+，并行项目不超过 2 个。**

这是我们最不愿意妥协的一条。

GEO 的交付质量高度依赖人的投入——问题集的构建、品牌事实的核对、母语内容的生产、信源的沟通，都需要深度理解客户的业务。**并行项目越多，单项目投入越薄，交付就越接近流水线。**

我们选择用产能上限换取交付质量：

| 项目      | 说明                      |
| ------- | ----------------------- |
| 单项目团队规模 | 10 人+                  |
| 同期并行项目  | 不超过 2 个                 |
| 团队构成    | 策略、技术、内容、本地化、客户成功       |
| 交付原则    | 精细化、高质量的数据提升，而非规模化的项目数量 |

**这意味着我们的接单能力有明确上限。** 如果你希望在窗口期内建立 AI 可见度壁垒，建议尽早沟通排期。

## 三、核心方法论

我们的方法论可概括为三层：**增长飞轮（打什么）→ 交付体系（怎么打）→ 问题工程（打准什么）**。

### 3.1 GEO 增长飞轮

六条战术，构成一个持续运转的循环：

| #  | 战术         | 内容                         |
| -- | ---------- | -------------------------- |
| 01 | **诊断与策略**  | 诊断当前平台可见度与痛点，输出破局策略        |
| 02 | **词库矩阵构建**   | 构建「痛点 + 场景 + 品类」关键词矩阵，拦截流量 |
| 03 | **权威内容铺设** | 针对品牌相对薄弱的平台，系统性铺设可信内容      |
| 04 | **品牌认知矫正**   | 用产品特性与事实，校正 AI 中的过时与错误表述   |
| 05 | **舆情护城河**  | 常态化监控，放大已有的正向口碑优势          |
| 06 | **全场景破圈**  | 从特定用户的垂直痛点，向大众日常需求渗透       |

### 3.2 五阶段交付体系

每个阶段由「执行动作」与「核心交付」共同定义。

#### 阶段 1 · 系统的诊断

| 执行动作  | 内容                       |
| ----- | ------------------------ |
| 全平台扫描 | 在目标市场的主流 AI 平台上全面扫描可见度表现 |
| 深度分析  | 分析品牌出现频率、推荐排名、评价倾向       |
| 竞品对标  | 与主要竞品进行多维度的可见度对标         |
| 风险识别  | 识别品牌 AI 认知优势点与潜在风险       |

**核心交付**：可见度基线数据 ／ AI 认知画像 ／ 竞品分析与风险识别

#### 阶段 2 · 针对性的策略

| 执行动作  | 内容                              |
| ----- | ------------------------------- |
| 专属策略  | 基于诊断数据和行业经验，为品牌制定专属的 GEO 优化策略   |
| 场景矩阵  | 构建用户提问场景矩阵，系统梳理用户可能向 AI 提出的关联问题 |
| 优先级排序 | 确定哪些平台、场景、关键词最需要优先突破            |
| 阶段执行  | 分阶段实施——短期速赢 + 中期深耕 + 长期壁垒       |

**核心交付**：整体思路与逻辑框架 ／ 平台 × 场景 × 关键词矩阵 ／ 分阶段实施计划 ／ 预期效果目标（量化的阶段性 KPI）

#### 阶段 3 · 专属的内容体系

| 执行动作    | 内容                              |
| ------- | ------------------------------- |
| 专属知识库   | 建立品牌专属知识库，系统化梳理品牌核心信息资产         |
| 原生内容生成  | 基于策略生产高质量的 GEO 原生内容，契合各 AI 平台偏好 |
| 全网矩阵式铺设 | 制定多渠道内容分发计划，最大化影响 AI 知识体系       |
| 多维质检    | 通过 30+ 维度的分析体系，严格把控内容质量与合规性     |

**核心交付**：品牌专属知识库 ／ GEO 优化原生内容（针对各主流 AI 平台定制）／ 分发计划与执行 ／ 质量分析验证报告

#### 阶段 4 · 共建 KPI 验证体系

| 执行动作     | 内容                            |
| -------- | ----------------------------- |
| 共识目标     | 与客户共建品牌 AI 可见度 KPI 体系，确保目标共识  |
| 量化对比     | 定期生成数据报告，量化对比优化前后的各维度变化       |
| **独立验证** | **通过多设备、多网络环境的独立验证，确保数据真实可信** |
| 全量存储     | 提供可视化数据看板，数据全量存储，支持历史回溯       |

**核心交付**：KPI 达成情况（排名、认知比例、竞品差距等）／ 可见度变化趋势（多维度折线图与对比图）／ 竞品动态分析 ／ 下阶段优化建议

> **为什么"独立验证"值得单独强调？**  
> AI 答案具有概率性——同一个问题在不同设备、不同网络、不同时间可能得到不同回答。只用一台电脑、一次截图得出的结论，不构成证据。  
> 我们通过多设备、多网络环境的独立验证，让每一条数据都能被复现。**这是我们与"截图式交付"最本质的区别。**

#### 阶段 5 · 持续优化与迭代

| 执行动作  | 内容                        |
| ----- | ------------------------- |
| 全天候监控 | 监测系统全天候运行，动态追踪表现变化        |
| 动态优化  | 基于最新数据持续优化策略与内容，拒绝一次性交付   |
| 竞品追踪  | 竞品动态实时追踪，竞品发生异常变化时及时调整    |
| 算法适配  | AI 平台算法更新和模型迭代后快速适配，保持竞争力 |
| 异常响应  | 负面舆情或排名异常的应急处理            |

**核心交付**：持续优化建议与执行 ／ 月度复盘报告 ／ 行业趋势洞察分享

### 3.3 问题工程：从问题库到关键词结构

**这是 DeepFocus 与"内容代发"最本质的分野——别人从内容出发，我们从问题出发。**

#### 3.3.1 四类问题来源

| 来源           | 定义                                            | 解决什么问题                              |
| ------------ | --------------------------------------------- | ----------------------------------- |
| **真实对话日志**   | 来自品牌方日常和电商渠道的真实对话语料，包含售前、售中、售后的提问，以及用户长期关注的问题 | 最贴近真实意图的语料                          |
| **品牌场景**     | 由品牌现有业务、产品线、核心卖点和重点市场构成的种子问题集合                | 从哪些核心主题出发，去做后续语义扩展                  |
| **竞品与比较场景**  | 来自用户在 AI 平台上的比较型、评测型、选择型问题                    | 品牌在"与谁比较""为什么被比较""在哪些场景里被放在一起"上的机会点 |
| **全网社交平台内容** | 来自主流社交平台上的用户讨论、标签、话题与问题合集                     | 品牌在真实社区语境下被怎样讨论、被放在哪些场景里、与哪些需求绑定    |

#### 3.3.2 三层结构映射

把问题按**行业、话题、场景和意图**组织起来，最终形成可监控、可迭代、可指导内容生产的结构化清单。

| 层级               | 定义                   | 示例                  |
| ---------------- | -------------------- | ------------------- |
| **第一层：行业**       | 定义品牌所在的业务大类          | 智能硬件、数码 3C、新消费、工业制造 |
| **第二层：话题**       | 定义行业下最核心的用户关注点       | 产品推荐、产品对比、使用教程、场景适配 |
| **第三层：子话题 + 意图** | 明确用户到底在问什么，以及问题背后的意图 | 信息型、比较型、交易型、导航型     |

#### 3.3.3 四步生成逻辑

| 步骤             | 内容                     |
| -------------- | ---------------------- |
| **语义召回**       | 从真实问题库里找出与品牌主题最接近的真实提问 |
| **语义聚类**       | 把表达不同、意思相近的问题聚到一起      |
| **意图识别**       | 判断问题到底是在了解、比较、选择还是购买   |
| **Prompt Gap** | 找出"用户在问、品牌没覆盖"的空白      |

#### 3.3.4 关键词结构：60 / 30 / 10 金字塔

> **核心策略：用 60% 的塔基词做内容密度，30% 的塔身词刷专业权重，最终 10% 的塔尖词实现最大可见度转化。**

| 层级     | 占比  | 词类型  | 作用                  |
| ------ | --- | ---- | ------------------- |
| **塔基** | 60% | 塔基词  | 确立专业度 → 让 AI 信任你专业  |
| **塔身** | 30% | 对比词  | 刷权威权重 → 让 AI 认定你是专家 |
| **塔尖** | 10% | 高竞争词 | 突破核心场景 → 在最难的位置抢占答案 |

### 3.4 用户转化五阶段

这套阶段划分回答了一个具体问题：**内容到底该写成什么样？**

针对处于不同认知阶段的用户，AI 答案应当呈现不同形态。

| 阶段         | 用户状态                      | 内容的机会点                        |
| ---------- | ------------------------- | ----------------------------- |
| **一、问题感知** | 只是"感觉不对"，尚未明确问题具体是什么      | 判断是否为常见类型，给出基础性解释与安抚，帮助建立判断框架 |
| **二、问题界定** | 开始尝试确认问题的类型和原因，希望把混乱的理解理清 | 结构化分类，建立清晰的判断框架，引导用户逐步聚焦      |
| **三、方案理解** | 想知道"通常怎么解决"，关注主流的解决路径     | 引入专业共识，帮助用户建立合理的预期            |
| **四、专业验证** | 希望确认方案是否长期可靠、是否得到专业认可     | 引入第三方验证，增强信息可信度，支持用户做出更稳健的决策  |
| **五、行动转化** | 已准备采取具体行动                 | 给出明确的执行方案，促使用户完成最后的转化步骤       |

### 3.5 海外 GEO 的三层本地化

**这是国内 GEO 团队做海外时最容易失败的地方。**

海外 GEO 与国内 GEO 的关键差异不在引擎列表，而在于：**你在目标市场有没有可被引用的母语信源。**

我们把海外交付拆成三个必须同时成立的层次：

| 层次          | 内容                       | 缺失的后果                          |
| ----------- | ------------------------ | ------------------------------ |
| **第一层：语言层** | 目标语言的母语级内容生产             | 机器翻译内容会被 AI 平台识别，推荐频率显著低于母语内容  |
| **第二层：信源层** | 目标市场的本地媒体、垂直评测、行业协会、社区内容 | 没有本地信源，AI 只能引用英文来源或竞品，品牌无法进入答案 |
| **第三层：平台层** | 目标市场的本地 AI 入口            | 只做全球引擎，等于放弃本地市场约一半的 AI 曝光      |

**以东亚市场为例：**

- **韩国**：AI 搜索不是单一市场，而是两个重叠的生态——Naver 的 AI 答案层（月活约 3000 万，覆盖约 27% 搜索查询）与 ChatGPT（韩国 app 月活约 2345 万）。韩国用户的日常搜索仍以 Naver 为起点，但研究型提问会转向 ChatGPT。**只管理其中一个生态，就会丢掉近一半的曝光。**
- **日本**：ChatGPT 是采用度最高的入口，但日语提问的引用来源高度本地化——日文维基、日本新闻媒体、日本问答站点。**英文内容资产在日本市场的迁移效率极低。**

**结论**：海外 GEO 的成本结构里，本地语言内容与本地信源建设占大头。这也是我们坚持定制化、不做标准品的根本原因。

### 3.6 交付节奏与合理预期

我们不做"X 天上榜"的承诺。以下是基于项目实践给出的合理预期：

| 阶段       | 合理预期                                      |
| -------- | ----------------------------------------- |
| 第 1-2 周  | 品牌信息标准化完成，AI 可识别基础品牌实体。**此阶段无明显推荐变化，属正常** |
| 第 3-4 周  | 部分平台开始出现品牌零星提及                            |
| 第 5-8 周  | 主要目标问题下稳定进入推荐列表。**见效是"稳定出现"，不是"永远第一"**    |
| 第 3-6 个月 | 推荐频率与位置趋于稳定，来自 AI 的咨询可被感知                 |
| 6 个月以上   | 建立权重壁垒。需持续维护，停止优化后会缓慢下滑                   |

**关于分阶段目标**：我们与客户共同约定「短期速赢 + 中期深耕 + 长期壁垒」的三段式目标，每一段都有可量化的阶段 KPI，而不是只给一个年底数字。

### 3.7 指标体系与数据验证

**六项指标，构成完整的可见度画像：**

| 指标        | 英文                  | 定义                   | 回答的问题               |
| --------- | ------------------- | -------------------- | ------------------- |
| **提及率**   | Mention Rate        | 目标问题集中品牌被提及的比例       | 用户问行业推荐时，AI 会提到你吗   |
| **推荐率**   | Recommendation Rate | 提及品牌的问题中，被列为首位／首选的比例 | 提到你时，是排第一还是垫底       |
| **引用率**   | Citation Rate       | 品牌内容被作为信息来源引用的比例     | AI 引用的是你的内容，还是别人的转述 |
| **认知准确度** | Fact Accuracy       | AI 描述品牌事实的正确比例       | AI 有没有把你说错          |
| **竞品差距**  | Competitor Gap      | 与主要竞品在各维度上的可见度差值     | 你和竞品差多远             |
| **品牌情感**  | Sentiment           | AI 对品牌描述的倾向（正／中／负）   | AI 在说你什么            |


**数据验证的三条原则：**

1. **固定口径**——问题集、平台清单、采样频率在项目开始时即锁定，中途变更需双方确认。
2. **独立可复现**——多设备、多网络环境验证；所有数据附问题原文、时间戳与截图存证，客户可独立复测。
3. **不混淆层级**——可见度数据、需求信号数据（品牌搜索量、AI 来源会话）与收入数据分层呈现，**绝不把第一层数据包装成收入**。

> **我们主动说明一件事**：AI 答案由概率分布生成，不同用户、会话、地域的结果会存在差异；部分平台的引用行为也可能被第三方工具低估。因此我们以**周期采样和趋势**而非单次截图作为结论依据——这是我们做数据披露时的一条基本纪律。

### 3.8 合规准则

| 准则              | 说明                                    |
| --------------- | ------------------------------------- |
| **内容基于真实公开信息**  | 所有内容以品牌真实公开信息为基础，经事实核对、质量校验与人工审核后进入分发 |
| **全程可追溯**       | 内容与分发记录完整留存，客户可复核每一条被引用的来源            |
| **不做语料投毒**      | 不使用批量软文投喂、虚构产品信息等手段                   |
| **不做虚假评价与伪造榜单** | 不制造虚假评论、不伪造专家署名、不伪造行业榜单               |
| **不贬损竞争对手**     | 不通过贬低竞品获取 AI 推荐位                      |
| **不承诺绝对排名**     | 生成式引擎是概率系统，我们承诺可复现的口径与可验证的提升，不承诺固定排名  |
| **高监管行业单独审查**   | 医疗、金融、保健、儿童类产品须先做独立合规审查               |

## 五、行业 FAQ

### A. 概念与认知

**A1. 什么是 GEO？**  
GEO（Generative Engine Optimization，生成式引擎优化）是围绕生成式 AI 的内容分发与推荐机制，对内容结构、数据标记、品牌实体与权威性进行多维度优化，让品牌信息被 AI 正确理解、主动提及、优先推荐。用户的交互模式正从"输入关键词获取十条链接"转变为"提出问题直接获得结构化答案"，GEO 就是为这个新入口做的优化。

**A2. GEO 和 SEO 有什么区别？**  
SEO 争的是搜索结果里的排名，用户点进去才算流量；GEO 争的是 AI 答案里的提及与推荐，**不用点击就能被看见**。SEO 的路径是"关键词 → 网页链接 → 点击跳转"，GEO 简化为"提问 → 答案"。两者不冲突，但 GEO 额外要求信息结构化、品牌口径统一、第三方信源权威。

**A3. GEO 会取代 SEO 吗？**  
不会。对绝大多数品牌而言，AI 搜索中的可见度问题是**新增的一层问题**，不是 SEO 的替代。GEO 需要独立布局，与 SEO、内容营销、公关投放是协同关系。

**A4. AI 是怎么决定提不提我的？**  
它不会只读官网，而是把问题拆成多个子检索，综合官网、行业媒体、社交平台、参考网站、评论平台等多来源后生成答案。所以 GEO 的本质不是"优化官网"，而是**同时建设官网内容与站外存在感**。

**A5. 为什么说"别人对你的描述比你自己的描述更重要"？**  
因为当 AI 实时检索时，它会对来源排序、提取片段、再输入模型。你自己的官网只是众多来源之一。真正决定结果的，是你在那些被 AI 优先选取的来源里存在感有多强。

### B. 出海与本地化

**B1. 中国品牌做海外 GEO，最难的是什么？**  
不是语言，是**信源**。海外生成式引擎大量引用本地媒体、垂直评测、行业协会与社区内容，而中国品牌在这些渠道的实体存在普遍薄弱。真正的杠杆点在第三方信源建设，不是官网改版。

**B2. 多语言内容机器翻译行不行？**  
不行。机器翻译能解决字面正确，解决不了意图差异、术语习惯、价格与单位表达、合规声明与本地信任信号。而且机器翻译内容可以被 AI 平台识别，在推荐中的表现通常低于母语内容。**最容易失败的做法就是"一个英文页翻译成十种语言"。**

**B3. 只做全球引擎够不够？**  
不够。以韩国为例，ChatGPT 与 Naver 是两个重叠的生态，只管理其中一个，等于放弃约一半的 AI 曝光。目标市场若有独立的 AI 入口，必须单独覆盖。

**B4. 英文市场的品牌权威能用到日本、韩国吗？**  
迁移效率很低。日韩的 AI 搜索呈现明显的母语信源偏好——日语、韩语提问的引用来源高度本地化。英文内容资产需要重新建设本地语言层。

### C. 效果与衡量

**C1. 多久能看到效果？**  
通常 4-8 周开始出现变化，3-6 个月趋于稳定。前 1-2 周属于品牌信息标准化阶段，**此时没有明显推荐变化是正常的**。见效周期与行业竞争程度、目标市场数量相关。

**C2. 效果怎么量化？**
看六项指标：提及率、推荐率、引用率、认知准确度、竞品差距、品牌情感。固定问题集与平台清单周期实测，全部附问题原文、时间与截图存证，并通过多设备、多网络环境独立验证，**支持客户侧独立复测**。

**C3. 为什么不能承诺"排第一"？**  
因为不存在稳定的"第一"。AI 答案由概率分布生成，跨会话、跨用户、跨地域结果会不同，模型也在持续更新。承诺固定排名的服务商，要么在赌低概率事件，要么用单次截图定义"达标"。

**C4. AI 答案不带来点击，价值在哪？**  
价值分两层：认知层的"进入候选集"，决策层的"被推荐"。可观测的中间信号包括品牌搜索量提升、AI 来源会话、AI 参与的转化路径、客户自报来源。我们提供分层归因，但不会把可见度数据包装成收入。
